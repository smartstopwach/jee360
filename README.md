# JEE360

A complete companion for JEE (Joint Entrance Examination) preparation.

## About

JEE360 aims to be a one-stop resource for JEE Main & Advanced aspirants — covering study material, practice questions, mock tests, and progress tracking.

## Getting Started

This is a fresh project scaffold. Setup instructions will be added as the project develops.

```bash
git clone https://github.com/<your-username>/jee360.git
cd jee360
```
